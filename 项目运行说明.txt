
环境：
python 3.8.0
node-v12.16.1

一、导入数据库文件
下载安装好MySQL数据库，新建数据库flask_douban_comment，通过Navicat软件将flask_douban_comment.sql导入  （默认端口3306  账号root 密码123456）

二、后端
1、pycharm软件打开整个项目文件夹
2、配置本地python编译器（建议新建虚拟环境）
3、安装依赖库，在Teminal窗口分别执行：
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
python -m pip install --upgrade pip
pip install -r requirements.txt

4、运行app.py

三、前端
1、打开teminal窗口，进入vue文件夹：cd vue
2、启动命令： npm run serve

四、访问网页
1、浏览器打开网站：前端弹出的链接
